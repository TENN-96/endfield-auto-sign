# Endfield 自动签到（GitHub Actions）

这是一个基于 **GitHub Actions** 的 Endfield（国际服 / skport）每日自动签到脚本。  
无需本地运行、无需保持浏览器开启，支持 **定时执行 + Discord 通知**。

---

## 功能特性

- ✅ 每日自动签到
- ⏰ GitHub Actions 定时运行
- 🤖 无需本地环境
- 🔔 Discord Webhook 通知结果
- 👤 支持多账号（可选）

---

## 使用前准备

### 1. GitHub 账号
免费账号即可。

### 2. Discord Webhook
用于接收签到结果通知。

创建方式：  
Discord 服务器 → 频道设置 → 整合（Integrations）→ Webhook
